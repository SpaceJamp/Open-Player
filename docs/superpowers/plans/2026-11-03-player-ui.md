# Player UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mouse-driven player window: control bar, info overlay, right-click menu, open/drag-and-drop with recent files, window icon.

**Architecture:** Dear ImGui draws on top of the video inside `Display::present` (a render pass after the blit). A new `player/ui.{h,cpp}` turns a per-frame state struct into a list of actions; `main.cpp` applies actions through the same functions the keyboard uses. Opening another file re-executes the player.

**Tech Stack:** C++17, SDL3 3.4, Vulkan (classic render pass), CUDA, Dear ImGui v1.93.0 (vendored).

**Spec:** `docs/superpowers/specs/2026-11-03-player-ui-design.md`

## Global Constraints

- Dear ImGui **v1.93.0**, vendored under `player/third_party/imgui/` (core files, `LICENSE.txt`, `backends/imgui_impl_sdl3.*`, `backends/imgui_impl_vulkan.*`; not `imgui_demo.cpp`). No system package.
- Classic `VkRenderPass`, not dynamic rendering (WSL's dzn).
- Overlay cost at 1080p60 -> 4K with the fast model: at most ~1 ms per frame, no added dropped frames.
- Recent files: max 10, newest first, no duplicates, missing files dropped when shown; `$XDG_CONFIG_HOME/open-player/recent.txt`, default `~/.config/open-player/recent.txt`, one path per line.
- Control bar hides 2 s after the last mouse movement; always shown while paused or hovered.
- Every existing key shortcut stays; `I` toggles the info overlay.
- Build and run everything in Arch WSL: `cmake --build build -j`; tests run offscreen (`tests/smoke.sh`, `tests/codecs.sh`).

## Review Focus

- Video paths with spaces and non-ASCII characters must survive re-exec and the recent-files file unchanged (test in Task 5).
- A minimized window (swapchain extent 0) skips presenting; ImGui must still end each frame (`ImGui::Render`) or the next `NewFrame` asserts (test in Task 3: several frames with no present).
- Videos with unknown duration (raw `.h264`, `dur <= 0`): the seek slider is disabled and drawing must not divide by zero (test in Task 3).
- Resize and fullscreen recreate the swapchain; the render pass framebuffers must be recreated with it (manual check in Task 2; offscreen tests can't resize).
- Missing or unreadable config directory: recent files load as empty and saving fails silently (test in Task 1).

### Task 2: Vendor ImGui; draw it in `Display`

**Files:**
- Create: `player/third_party/imgui/` (files per Global Constraints, from tag `v1.93.0`)
- Modify: `player/CMakeLists.txt`, `player/display.{h,cpp}`, `player/main.cpp`

**Interfaces:**
- Consumes: nothing from Task 1.
- Produces:
  - `bool Display::init_imgui();` creates the render pass, per-image views and framebuffers, a descriptor pool, and calls `ImGui_ImplVulkan_Init` (returns false on any failure; the player then runs without UI).
  - `bool Display::present(int w, int h, cudaStream_t s, bool new_frame);` — replaces the 3-argument version. Skips the buffer->image copy when `new_frame` is false. After the blit, if ImGui is initialised and `ImGui::GetDrawData()` is non-null, runs the render pass recording `ImGui_ImplVulkan_RenderDrawData`; the pass's final layout is `PRESENT_SRC_KHR`.
  - `make_swapchain()` adds `VK_IMAGE_USAGE_COLOR_ATTACHMENT_BIT` and recreates views and framebuffers.
