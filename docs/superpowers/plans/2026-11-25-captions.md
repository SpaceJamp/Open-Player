# Captions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** English captions (text and picture subtitles, embedded or a `.srt` beside the video) drawn sharp over
the video, with C / CC button / menu / Settings controls.

**Architecture:** A new unit `captions.{h,cpp}` holds everything testable without a GPU: track listing and the
default choice, cue decoding from FFmpeg subtitle packets, text cleaning, cue lookup, sidecar files, encoding and
picture placement. `Media` feeds the chosen stream's packets to it on its decode thread; the UI draws the active
cues after the video, through ImGui (text) and ImGui Vulkan textures (pictures).

**Tech Stack:** C++20, FFmpeg (libavcodec/libavformat, already in the build), Dear ImGui + Vulkan backend.

**Spec:** `docs/superpowers/specs/2026-11-25-captions-design.md`

## Global Constraints

- English only: language `eng`/`en`, untagged streams, and `.srt` beside the video without a non-English language
  suffix. No new dependencies (no libass, no fonts).
- Default track when on: first SDH (title contains "SDH", case-insensitive, or `AV_DISPOSITION_HEARING_IMPAIRED`),
  else first English not forced-only, else first English.
- Forced English track shows even with captions off; with captions on, the chosen track replaces it.
- `captions=1|0` in settings.txt, default 0; C, the CC button, the menu and Settings > General "Captions" all save it.
- Text: white Inter, black outline (8 offsets), size 4.6% of window height, wrap at 80% width, max 3 lines, bottom
  centre, lifted above the control bar while it shows. Picture: canvas centred on the shown picture, clamped into the
  window, lifted like text.
- A cue without an end lasts until the next cue or 5 s. Seek clears cues.
- Windows only for testing; keep the Linux build compiling.
- Commit and push after every task on branch `captions`; end with 4 bug-check agents (one security).

## Review Focus

- A `.srt` beside the video in Windows-1252 (accented letters): shows correct text, not garbage (Task 1 test).
- Text with `<i>`, `{\an8}`, `\N` and HTML entities `&amp;`: shown as plain readable text (Task 1 test).
- A huge or hostile subtitle (100 000-character line, 10 000 cues, a 16000x16000 PGS rect): no hang, no giant
  allocation (Task 2 tests: text cut to 1000 chars, cues capped at 20 000, picture rects over 4096x4096 skipped).
- Overlapping cues (two lines active at once): both shown, earlier first (Task 1 test).
- Seeking backwards: old cues gone, no stale line stays on screen (Task 3 test via `clear` on serial change).
